# Access a child layout

Access a child layout

## Usage

``` r
child_layout_offsets(layout)

child_layout_geometry(layout)
```

## Arguments

- layout:

  An `explodemap_child_layout` from
  [`layout_children()`](https://prigasg.github.io/explodemap/reference/layout_children.md).

## Value

`child_layout_offsets()` returns the renderer-neutral offset table;
`child_layout_geometry()` returns the composed projected `sf` geometry.
