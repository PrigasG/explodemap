# HHS regional assignments for states and territories

Returns the lookup table used by the explodemap gallery's national HHS
view. It includes the 50 states, District of Columbia, Puerto Rico, U.S.
Virgin Islands, Guam, American Samoa, and the Northern Mariana Islands.

## Usage

``` r
hhs_regions()
```

## Value

A data frame with state name, postal/territory code, region id, and
display labels.
